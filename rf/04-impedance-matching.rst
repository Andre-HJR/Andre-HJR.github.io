======================================
阻抗匹配
======================================

阻抗匹配是射频设计中最基本也最重要的任务——使源阻抗、传输线阻抗和负载阻抗一致，
实现**最大功率传输**和**最小反射**。

匹配的必要性
=============

.. code-block::

   失配的后果：

   1. 功率损失：反射功率 = |Γ|² × 入射功率
   2. 信号失真：多径反射造成码间干扰
   3. 器件损坏：高反射功率可能损坏功放
   4. 频率响应畸变：滤波器等器件的性能恶化

   匹配的目标：

   Γ → 0, VSWR → 1:1, RL → -∞ dB

L 型匹配网络
===============

L 网络是最简单的匹配网络，仅用两个电抗元件。

.. code-block::

   L 网络拓扑结构（4 种基本形态）：

          ┌─── L ───┐               ┌─── L ───┐
   Z_s ──┤         ├── Z_L    Z_s ──┤         ├── Z_L
          └─ C ──┐  │               └─ ──┐ ──┘
                  │  │                    │
                  ═══                    ═══ GND
   (a) Z_L > Z_s 低通               (b) Z_L < Z_s 高通

          ┌─── C ───┐               ┌─── C ───┐
   Z_s ──┤         ├── Z_L    Z_s ──┤         ├── Z_L
          └─ L ──┐  │               └─ ──┐ ──┘
                  │  │                    │
                  ═══                    ═══ GND
   (c) Z_L > Z_s 高通              (d) Z_L < Z_s 低通

.. note::

   L 网络的特性：
   - **最简匹配**：最少元件数（2个）
   - **有载 Q 值固定**：不能独立选择 Q 值
   - **窄带**：适合窄带应用

L 网络设计步骤
---------------

.. code-block::

   例：将 Z_L = 25 + j10 Ω 匹配到 50 Ω (f = 1 GHz)

   步骤 1：判断 Z_L 位于史密斯圆图上的位置
   步骤 2：选择合适拓扑（高阻侧串联电感/低阻侧并联电容）
   步骤 3：使用圆图或公式计算元件值

   公式法（以低通 L 匹配为例）：

   设 R_s > R_L：

   Q = √(R_s/R_L - 1)      其中 R_s 为源阻抗
   X_L = Q · R_L           串联感抗
   X_C = R_s / Q           并联容抗

   L = X_L / (2πf)         C = 1 / (2πf X_C)

   计算：
   Q = √(50/25 - 1) = 1
   X_L = 1 × 25 = 25 Ω
   X_C = 50 / 1 = 50 Ω

   L = 25 / (2π × 1e9) ≈ 3.98 nH
   C = 1 / (2π × 1e9 × 50) ≈ 3.18 pF

.. tip::

   实际设计中，L 值可选用标准值（3.9 nH、4.3 nH），
   再用 C 微调来补偿 L 的离散误差。

π 型匹配网络
===============

.. code-block::

   π 型网络拓扑：

   Z_s ──────┬─── L ───┬────── Z_L
             │         │
             ═ C₁      ═ C₂
             │         │
             ═══════════ GND

π 网络的特性：

- **3 个元件** (2 电容 + 1 电感，或反之)
- **可独立选择 Q 值**——带宽可控
- **可实现阻抗转换**：输入/输出均可匹配
- **适合宽带匹配**：Q 值可调低以获得更宽带宽

π 网络设计公式：

.. math::

   X_{C1} = \frac{R_s}{Q} \quad
   X_{C2} = \frac{R_L}{\sqrt{(1+Q^2)\frac{R_L}{R_s} - 1}}

   X_L = \frac{Q R_s + \frac{R_s R_L}{X_{C2}}}{Q^2 + 1}

.. code-block::

   例：将 10 Ω 匹配到 50 Ω，Q = 5，f = 2 GHz

   X_{C1} = 10 / 5 = 2 Ω
   → C1 = 1 / (2π × 2e9 × 2) ≈ 39.8 pF

   X_{C2} = 50 / √((1+25)×50/10 - 1) = 50 / √(130 - 1) = 50 / √129 ≈ 4.4 Ω
   → C2 = 1 / (2π × 2e9 × 4.4) ≈ 18.1 pF

   X_L = (5×10 + 10×50/4.4) / (25+1) ≈ (50 + 113.6) / 26 ≈ 6.29 Ω
   → L = 6.29 / (2π × 2e9) ≈ 0.5 nH

T 型匹配网络
===============

.. code-block::

   T 型网络拓扑：

   Z_s ──┬── L₁ ───┬─── L₂ ──┬── Z_L
         │         │         │
         ═════════ C ────────
         │         │         │
         ═════════════════════ GND

T 网络的特性与 π 网络相似，但适用于不同的阻抗范围。

π 网络 vs T 网络选择：
- π 网络：适用于源阻抗 > 负载阻抗
- T 网络：适用于源阻抗 < 负载阻抗

分布式匹配
=============

四分之一波长阻抗变换器
-------------------------

.. code-block::

   λ/4 变换器：

   Z_s ──── [λ/4, Z_q] ──── Z_L

   Z_q = √(Z_s × Z_L)

   例：将 50 Ω 匹配到 100 Ω
   Z_q = √(50 × 100) = 70.71 Ω

.. note::

   四分之一波长变换器是**窄带**匹配方案。
   多节四分之一波长变换器（如二节、三节切比雪夫渐变线）
   可以获得更宽的带宽。

渐变线（Taper）
-----------------

.. code-block::

   线性渐变线：

   Z_s ──── [Z=Z_s → Z=Z_L, 长度=λ/2] ──── Z_L

   渐变线是最宽带的匹配结构之一，但需要较长的物理尺寸。
   Klopfenstein 渐变线是最优渐变线（最陡的过渡）。

匹配元件的高频实现
====================

.. list-table::
   :header-rows: 1

   * - 元件
     - 低频等效
     - 高频实现方式
     - 注意事项
   * - 电容
     - 贴片 MLCC
     - 0402/0603 封装
     - SRF 需 > 工作频率
   * - 电感
     - 绕线/叠层
     - 高频空心线圈
     - SRF 和 Q 值关键
   * - 接地
     - 过孔到地
     - 多个并联过孔
     - 过孔电感约 0.5 nH
   * - 传输线
     - 短截线 (Stub)
     - 开路/短路短截线
     - 长度 < λ/4

.. important::

   在 GHz 频段，匹配元件的**自谐振频率（SRF）**必须高于工作频率。
   电容超过 SRF 后会表现为电感，电感超过 SRF 后会表现为电容。

   选择元件时需检查 S 参数或 datasheet，
   确保在目标频段内元件特性正确。
