======================================
射频电路设计
======================================

本章介绍射频电路设计中的关键模块：放大器、滤波器、混频器和振荡器。

小信号放大器设计（LNA）
-------------------------

.. code-block::

   低噪声放大器（LNA）的设计目标：

   1. 最小化噪声系数 NF
   2. 提供足够增益 (S₂₁ > 10 dB)
   3. 良好的输入/输出匹配 (S₁₁ < -10 dB, S₂₂ < -10 dB)
   4. 足够的线性度 (IIP3 > -10 dBm)

   LNA 常用拓扑：

   ┌─────────── Vdd
   │
   ├── L_choke
   │
   ┌┴┐
   │ │ R_d
   └┬┘
   │
   C_out
   ├──┬── RF_out
   │  │
   ┌┴┐ ═══ C_bypass
   │ │
   │ │ L_s   ← 源极退化电感（噪声匹配）
   │ │
   ═══     GND

噪声系数 (NF)
--------------

.. math::

   F = F_{\min} + \frac{R_n}{G_s} |Y_s - Y_{\text{opt}}|^2

   \text{NF} (\text{dB}) = 10 \log_{10} F

- :math:`F_{\min}` ：最小噪声系数
- :math:`R_n` ：等效噪声电阻
- :math:`Y_{\text{opt}}` ：最佳噪声导纳

.. important::

   在 LNA 设计中， **噪声匹配** 和 **功率匹配** 通常不是同一个点——
   最小噪声点与最大增益点在史密斯圆图上不重合。设计需在噪声和增益间权衡。

   ADS 可用 **Smith Chart Matching** 工具同时显示噪声圆和增益圆。

放大器稳定性
-------------

.. code-block::

   稳定性分析（使用 S 参数）：

   1. 计算 Rollett 稳定因子 K：
        K > 1 且 |Δ| < 1 → 无条件稳定

   2. 若 K < 1，需增加稳定网络：
       - 在栅极串联小电阻（降低低频增益）
       - 在漏极并联 RC 网络
       - 在输出加隔离器

-----------

   :header-rows: 1

   * - 类型
     - 响应
     - 特点
     - 应用
   * - 巴特沃斯

微带滤波器实现
---------------

.. code-block::

   平行耦合微带带通滤波器（三阶示例）：

         λ/4          λ/4          λ/4
   ┌──────────┐  ┌──────────┐  ┌──────────┐
   │ Port 1  │  │          │  │ Port 2  │
   │ ──────  │  │ ──────── │  │ ──────  │
   │         │  │          │  │         │
   │ ──────  │  │ ──────── │  │ ──────  │
   └──────────┘  └──────────┘  └──────────┘
     耦合间隙      耦合间隙

   耦合间隙 g 决定耦合系数 → 影响滤波器带宽
   谐振器长度 = λ/4（短路）或 λ/2（开路）

滤波器设计参数
---------------

.. math::

   插入损耗：IL \approx \frac{4.34}{Q_u} \sum_{i=1}^n g_i \ (\text{dB})

   3-dB 带宽：BW = \frac{f_0}{Q_L} \times 100\%

   带外抑制：每增加一阶增加约 6 dB/倍频程（巴特沃斯）

混频器
========

.. code-block::

   混频器原理：

   f_RF (输入) ──┐
                  ├── 非线性器件 ── 中频输出
   f_LO (本振) ──┘

   f_IF = |f_RF ± f_LO|

   常用混频器拓扑：

   单管混频器：
   ┌────────────────────┐
   │  RF ───┬── Diode ──┼── IF
   │        │           │
   │  LO ───┴───────────┤
   │        L/C 匹配     │
   └────────────────────┘

   吉尔伯特双平衡混频器（集成）：
   用晶体管堆叠实现，提供更好的端口隔离度。

混频器关键指标：

- **转换增益** (或损耗)：RF 输入到 IF 输出的功率比
- **端口隔离度**：LO → RF、LO → IF、RF → IF 的泄漏
- **IIP3 / 1-dB 压缩点**：线性度指标
- **噪声系数**：包括镜像噪声

振荡器
========

.. code-block::

   Colpitts 振荡器（电容三点式）：

   ┌───────── Vdd
   │
   ├── RFC
   │
   ┌┴┐
   │ │
   └┬┘
   │
   ├── C₁ ──┬── C₂ ── GND
   │        │
   └────────┴── L ──── GND

   振荡条件：

   1. 环路增益 |Aβ| ≥ 1
   2. 环路相移 ∠(Aβ) = 360° (0°)

   VCO（压控振荡器）中用变容二极管代替固定 C₁ 或 C₂
   来实现频率调谐。

相位噪声
---------

.. math::

   \mathcal{L}(\Delta f) = 10 \log_{10} \left[ \frac{2FkT}{P_s} \left(1 + \left(\frac{f_0}{2Q\Delta f}\right)^2\right) \right]

   \text{其中：} P_s = \text{信号功率, } Q = \text{谐振回路有载 Q}

- 相噪单位：dBc/Hz @ 偏移频率
- 每增加一倍的谐振腔 Q 值，相噪改善约 6 dB
- 每增加一倍的偏置频率，相噪下降约 20 dB/dec
