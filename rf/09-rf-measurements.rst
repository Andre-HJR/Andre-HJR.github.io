======================================
射频测量技术
======================================

射频测量是验证设计正确性、发现问题的关键环节。

矢量网络分析仪 (VNA)
=======================

VNA 是射频最核心的测量仪器，测量 S 参数。

工作原理
---------

.. code-block::

   VNA 内部架构（简化）：

                       ┌──────────┐
                     ┌─┤ 定向耦合器 ├─ a₁
                     │ └──────────┘
                     │ ┌──────────┐
   RF 源 ── 功分器 ──┼─┤ 定向耦合器 ├─ b₁
                     │ └──────────┘
                     │ ┌──────────┐
                     │ ┤ 定向耦合器 ├─ a₂
                     │ └──────────┘
                     │ ┌──────────┐
                     └─┤ 定向耦合器 ├─ b₂
                       └──────────┘

   VNA 测量入射波 (a) 和反射波 (b)，
   计算比值得到 S 参数。

VNA 校准
----------

.. code-block::

   校准是 VNA 测量中最重要的步骤。

   SOLT 校准（同轴校准件）：

   ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐
   │   Short   │  │   Open   │  │   Load   │  │  Thru    │
   │   短路     │  │   开路    │  │   50 Ω   │  │  直通    │
   └──────────┘  └──────────┘  └──────────┘  └──────────┘

   校准步骤：
   1. 连接 Short → 测量 Γ = -1
   2. 连接 Open → 测量 Γ = +1
   3. 连接 Load → 测量 Γ = 0
   4. 连接 Thru → 测量传输

   TRL 校准（用于非同轴/夹具测量）：
   - Thru (直通)：直接连接测试端口
   - Reflect (反射)：连接短路/开路
   - Line (延迟线)：连接已知长度传输线

.. important::

   校准后检查：
   - 直通测 S₂₁ ≈ 0 dB（±0.05 dB）
   - 负载测 S₁₁ < -40 dB
   - 开路测 S₁₁ 幅值 ≈ 0 dB，相位符合预期

频谱分析仪
==============

.. code-block::

   频谱仪工作原理（超外差式）：

   RF 输入 → 衰减器 → 混频器 → IF 滤波 → 检波 → 显示
                        ↑
                    本振 LO (扫频)

   关键设置：
   - RBW (分辨率带宽)：决定频率分辨能力，RBW 越小越精细
   - VBW (视频带宽)：视频滤波，平滑显示
   - Sweep Time：扫描时间
   - Reference Level：参考电平

RBW 的选择
------------

.. list-table::
   :header-rows: 1

   * - RBW
     - 频率分辨率
     - 灵敏度
     - 扫描速度
   * - 10 kHz
     - 粗
     - 较差
     - 快
   * - 1 kHz
     - 中
     - 适中
     - 中
   * - 100 Hz
     - 细
     - 好
     - 慢
   * - 10 Hz
     - 很细
     - 最好
     - 很慢

RBW 每降低 10 倍，底噪降低 10 dB，扫描时间增加约 10 倍。

噪声系数测量
==============

Y 因子法（冷/热源法）
-----------------------

.. code-block::

   噪声系数测量配置：

                  ┌──────────────┐
   噪声源 ──────→ │    DUT       ├──→ 频谱仪/噪声仪
    (ON/OFF)      │  (被测件)     │
                  └──────────────┘

   测量步骤：
   1. 连接噪声源到 DUT 输入
   2. 噪声源 ON（热态）→ 测量 N_hot
   3. 噪声源 OFF（冷态/常温）→ 测量 N_cold
   4. Y = N_hot / N_cold（Y 因子）

   NF = ENR - 10 log_{10} (Y - 1)

   ENR = 10 log_{10} (T_hot / T_0 - 1)
   T_0 = 290 K, T_hot ≈ 10,000 K

.. tip::

   噪声源在指定频率有已知的 ENR 值（通常标在噪声源标签上）。
   如：6 dB ENR ≈ T_hot ≈ 1,200 K

P1dB 与 IIP3 测量
======================

1-dB 压缩点
-------------

.. code-block::

   测量配置：信号源 → DUT → 频谱仪

   扫描输入功率，记录输出功率：

   Pout (dBm)
       ↑
       │    理想线性响应 (斜率 1:1)
       │   ／
       │  ／
       │  │  实际响应
       │  │  ／
       │  │ ／
       │  │／
       │  ●──── 1 dB 压缩点 (P1dB)
       │
       └─────────────────→ Pin (dBm)

   P1dB = 增益压缩 1 dB 时的输入功率
   OP1dB = P1dB + Gain - 1

三阶交调截点 (IIP3)
---------------------

.. code-block::

   测量配置：双音信号源 → DUT → 频谱仪

   双音信号：f₁ = 2.000 GHz, f₂ = 2.001 GHz

   频谱仪上观察到：
   基波：f₁, f₂
   三阶交调：2f₁-f₂, 2f₂-f₁ (距基波 1 MHz)

   IIP3 的测量：

   1. 输入双音信号（功率 P_in）
   2. 测量基波输出 P_f1 和三阶交调 IM3
   3. IIP3 = P_in + (P_f1 - IM3) / 2

测试注意事项
==============

.. code-block::

   1. 静电防护 (ESD)

      - 操作前佩戴接地腕带
      - 所有仪器共地
      - 敏感器件放在防静电盒中

   2. 电缆与连接

      - 使用高质量的稳相电缆
      - 连接前用扭矩扳手拧紧
      - 避免电缆弯曲半径过小（> 5 cm）
      - 定期清洁连接器（异丙醇 + 压缩空气）

   3. 仪器预热

      - VNA 预热至少 30 分钟
      - 保证环境温度稳定（±1°C）

   4. 功率限制

      - 确认 DUT 最大输出功率不超过仪器最大输入
      - 必要时加外部衰减器保护 VNA/频谱仪

   5. 参考面

      - 校准后不可以移动校准参考面
      - 使用去嵌入/端口延伸补偿夹具
