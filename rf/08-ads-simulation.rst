======================================
ADS 仿真思路与流程
======================================

ADS（Advanced Design System）是安捷伦/是德科技推出的射频与微波电路仿真工具，
在 RF 设计中占据主导地位。

ADS 仿真流程总览
===================

.. code-block::

   完整的 ADS 仿真流程：

   1. 项目建立
      └── 选择工艺库与技术文件

   2. 原理图设计
      ├── 调用元件库（S 参数、集总元件、传输线）
      ├── 设置仿真模板（S 参数 / 谐波平衡 / 瞬态）
      └── 设置参数扫描（频率、功率等）

   3. 仿真运行
      ├── 小信号分析（S 参数）
      ├── 大信号分析（谐波平衡 HB）
      ├── 瞬态分析（时域）
      └── 电磁仿真（Momentum / FEM）

   4. 数据显示
      ├── Smith 圆图
      ├── 幅度/相位曲线
      ├── 星座图 / EVM
      └── 大信号特性

   5. 优化
      ├── 目标设定（S₁₁ < -20 dB, S₂₁ > 10 dB）
      ├── 参数调谐（Tuning）
      ├── 自动优化（Optimization）
      └── 良率分析（Yield）

   6. 版图生成（Layout）
      ├── 原理图 → 版图（Layout）
      ├── EM 协同仿真
      └── 导出 Gerber / GDSII

常见仿真模板
==============

S 参数仿真模板
----------------

.. code-block::

   S 参数仿真（示例：微带滤波器）：

             ┌──────────────┐
   Port 1 ──┤   微带滤波器   ├── Port 2
    50 Ω    │    (DUT)      │   50 Ω
             └──────────────┘

   ADS 原理图中的设置：

   1. 放置 S_Param 控件
      S_Param
      Start=1.0 GHz
      Stop=3.0 GHz
      Step=1.0 MHz

   2. 设置 Term 组件（端口终端，通常 50 Ω）

   3. 运行仿真 → 查看 S₁₁、S₂₁ 曲线

谐波平衡仿真模板
------------------

.. code-block::

   谐波平衡仿真（示例：功率放大器）：

   ┌──────────┐    ┌──────────────┐    ┌──────────┐
   │ 源端     ├─── │     PA       ├─── │  负载    │
   │ P_1Tone  │    │   (DUT)      │    │ Term     │
   └──────────┘    └──────────────┘    └──────────┘

   HB 控制器设置：
   Freq[1] = 2 GHz (基频)
   Order[1] = 5 (谐波阶数)
   使用 Sweep 扫描输入功率

   | 输出：Pout(dBm) vs Pin(dBm)
   | Gain(dB) vs Pin(dBm)
   | PAE(%) vs Pin(dBm)
   | IMD3 vs Δf (双音)

ADS 调谐与优化
================

调谐（Tuning）
---------------

.. code-block::

   手动调谐——调整元件参数实时观察结果变化：

   步骤：
   1. 选中要调谐的元件（如 L、C 值）
   2. 点击工具栏里的 Tuning 按钮（或 View → Tuning）
   3. 在弹出的调谐面板中滑动滑条
   4. 结合史密斯圆图直观地观察匹配变化

   调谐技巧：
   - 先调大趋势（数量级），再微调
   - 观察 S₁₁ 在史密斯圆图上的轨迹
   - 每次只调一个参数，理解参数的影响

优化（Optimization）
---------------------

.. code-block::

   自动优化——设置目标后让 ADS 自动寻参：

   优化步骤：
   1. 在原理图中加入 Goal 控件

      Goal
      OptimGoal[1] = S11_dB
      SimInstanceName[1] = "SP1"
      Min[1] = -100
      Max[1] = -20
      RangeVar[1] = "freq"
      RangeMin[1] = 2.0 GHz
      RangeMax[1] = 2.5 GHz

   2. 在元件参数后加变量名（如 L=3 nH 改为 L=var_L nH）
   3. 在 VAR 控件中定义变量和范围

      VAR
      var_L = 2.0 (1.0 to 5.0)
      var_C = 1.0 (0.5 to 3.0)

   4. 选择优化算法

      - Random（随机）：全局搜索，适合初始探索
      - Gradient（梯度）：局部搜索，收敛快
      - Genetic（遗传）：全局搜索，适合复杂问题
      - Minimax（极小极大）：适合多目标

   5. 运行优化 → 查看优化结果

.. tip::

   优化的**黄金法则**：
   - 先手动粗调，再用自动优化精调
   - 限制变量范围避免物理不可实现的值
   - 分步优化（先匹配、后增益、再线性度）
   - 最终验证优化结果在极端工艺角下的表现

电磁仿真（Momentum / FEM）
=============================

.. code-block::

   原理图 → 版图 → EM 仿真的完整流程：

   1. 在原理图中完成电路设计并仿真
   2. 选中设计 → Layout → Generate/Update Layout
   3. 在版图窗口中设置：
      - 衬底（Substrate）定义
      - 端口（Port）设置
      - 网格（Mesh）密度
   4. 运行 Momentum（2.5D EM 仿真，适合平面结构）
      或 FEM（3D EM 仿真，适合非平面结构）
   5. EM 仿真完成后，生成 EM 模型符号
   6. 将 EM 模型放回原理图 → 协同仿真

常用的 ADS 设计示例
====================

示例：L 型匹配网络
-------------------

.. code-block::

   目标：将 Z_L = 25 + j10 Ω @ 1 GHz 匹配到 50 Ω

   ADS 实现步骤：

   1. 新建原理图，添加 S_Param 控件
      Start=0.5 GHz, Stop=1.5 GHz

   2. 放置负载和匹配元件：
      ┌────────────┬────────────┬────────────┐
      │ TermG      ┝ L=3.98 nH ┝ C=3.18 pF ┝ TermG
      │ Z=50 Ω     │           │           │ Z=25 Ω
      └────────────┴────────────┴────────────┘

   3. 在负载端加自定义阻抗（使用 Z1P_Eqn 控件）
      Z_L = 25 + j*10

   4. 仿真并查看 S₁₁ ← 验证匹配效果

   5. 运行 Tuning 微调 L、C 补偿寄生

示例：S 参数提取（去嵌入）
---------------------------

.. code-block::

   EM 仿真 + 去嵌入流程：

                     ┌── 去嵌入区域 ──┐
                     │                │
    ───── Port ────▓▓▓── DUT ──▓▓▓── Port ─────

   去嵌入原理：
   1. 分别仿真：
      - 直通结构（Thru）
      - 开路结构（Open）
      - 短路结构（Short）
   2. 使用 ADS 的去嵌入模板减去夹具寄生
   3. 得到 DUT 的纯 S 参数

   在 ADS 中可通过 "Simulation → De-embed" 向导完成。

示例：单级放大器的设计
------------------------

.. code-block::

   步骤大纲（以 BJT 放大器为例）：

   1. 选择晶体管（如 ATF-34143）
   2. DC 仿真确定偏置点（Vds = 3V, Ids = 20 mA）
   3. 在偏置点进行 S 参数仿真
   4. 评估稳定性 K 因子（若 K<1，加稳定网络）
   5. 设计输入/输出匹配网络
   6. 在原理图中仿真：S 参数 + HB 大信号
   7. 优化匹配元件值
   8. 生成版图并运行 EM 协同仿真
   9. 最终验证：增益、NF、P1dB、PAE
