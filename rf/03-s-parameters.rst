======================================
S 参数与史密斯圆图
======================================

S 参数（Scattering Parameters）是射频网络中**唯一实用**的测量参数，
因射频下无法直接测量电压和电流（需测入射/反射波）。

S 参数定义
============

二端口网络的 S 参数：

.. code-block:: text

                  ┌──────────┐
      a₁ ──────→ │          │ ←────── a₂
                  │  二端口   │
      b₁ ←────── │  网络    │ ──────→ b₂
                  └──────────┘

.. math::

   \begin{bmatrix} b_1 \\ b_2 \end{bmatrix} =
   \begin{bmatrix} S_{11} & S_{12} \\ S_{21} & S_{22} \end{bmatrix}
   \begin{bmatrix} a_1 \\ a_2 \end{bmatrix}

其中 :math:`a_i` 为入射波，:math:`b_i` 为反射波。

.. list-table::
   :header-rows: 1

   * - 参数
     - 名称
     - 含义
   * - :math:`S_{11}`
     - 输入反射系数（回波损耗）
     - 端口 1 的反射波 / 入射波（端口 2 匹配）
   * - :math:`S_{21}`
     - 正向传输系数（增益/插入损耗）
     - 端口 2 的输出波 / 端口 1 的入射波
   * - :math:`S_{12}`
     - 反向传输系数（隔离度）
     - 端口 1 的输出波 / 端口 2 的入射波
   * - :math:`S_{22}`
     - 输出反射系数
     - 端口 2 的反射波 / 入射波（端口 1 匹配）

.. important::

   **dB 形式的 S 参数：**

   .. math::

      |S_{11}|_{\text{dB}} = 20 \log_{10} |S_{11}| \quad (\text{回波损耗, RL})

      |S_{21}|_{\text{dB}} = 20 \log_{10} |S_{21}| \quad (\text{插入损耗/增益})

   例：:math:`S_{21} = 0.1\ (-20\ \text{dB})` 表示 -20 dB 插入损耗
        :math:`S_{21} = 10\ (+20\ \text{dB})` 表示 20 dB 增益

   **典型 RF 放大器：** :math:`S_{21} \approx 10-30\ \text{dB}` 、 :math:`S_{11} < -10\ \text{dB}`

二端口网络的稳定性
=====================

.. math::

   \Delta = S_{11}S_{22} - S_{12}S_{21}

   K = \frac{1 - |S_{11}|^2 - |S_{22}|^2 + |\Delta|^2}{2|S_{12}S_{21}|}

无条件稳定条件：:math:`K > 1` 且 :math:`|\Delta| < 1`

史密斯圆图（Smith Chart）
============================

史密斯圆图是射频工程最经典的图形化工具，将复数阻抗映射到反射系数平面。

.. code-block::

   史密斯圆图的核心映射：

          Z_L - Z_0
   Γ = ─────────────
          Z_L + Z_0

   归一化阻抗：z = Z_L / Z_0 = r + jx

   等电阻 r 圆：圆心 (r/(r+1), 0)，半径 1/(r+1)
   等电抗 x 圆：圆心 (1, 1/x)，半径 1/|x|

圆图上的关键点
---------------

.. list-table::
   :header-rows: 1

   * - 位置
     - 阻抗
     - 反射系数
     - 说明
   * - 中心点
     - :math:`Z_L = Z_0`
     - :math:`\Gamma = 0`
     - 完美匹配
   * - 最左端
     - :math:`0\ \Omega`
     - :math:`\Gamma = -1`
     - 短路
   * - 最右端
     - :math:`\infty\ \Omega`
     - :math:`\Gamma = +1`
     - 开路
   * - 上半圆
     - :math:`r + jx`
     - 感性
     - 正电抗
   * - 下半圆
     - :math:`r - jx`
     - 容性
     - 负电抗

史密斯圆图的应用步骤
======================

.. code-block::

   在史密斯圆图上进行阻抗匹配的基本步骤：

   步骤 1：将负载阻抗 Z_L 归一化：z = Z_L / Z_0
   步骤 2：在圆图上标记 z 点
   步骤 3：确定匹配策略（串/并联 L 或 C）
   步骤 4：沿等电阻圆或等电导圆移动到匹配点
   步骤 5：反归一化得到元件值

   圆图上的移动规则：

   ┌──────────────────────┬──────────────────────┬─────────────────────┐
   │ 元件                 │ 移动方向             │ 轨迹                │
   ├──────────────────────┼──────────────────────┼─────────────────────┤
   │ 串联电感 L           │ 沿等电阻圆向上        │ 增加正电抗           │
   │ 串联电容 C           │ 沿等电阻圆向下        │ 增加负电抗           │
   │ 并联电感 L           │ 沿等电导圆向上        │ 增加负电纳           │
   │ 并联电容 C           │ 沿等电导圆向下        │ 增加正电纳           │
   │ 串联传输线           │ 沿等 VSWR 圆顺时针    │ 向负载方向移动       │
   └──────────────────────┴──────────────────────┴─────────────────────┘

. 导纳圆图
-----------

有时使用导纳更方便。归一化导纳 :math:`y = 1/z = g + jb`：

- 史密斯圆图绕中心旋转 180° 即为导纳圆图
- 通常阻抗圆图和导纳圆图叠加使用

S 参数测量
=============

.. code-block::

   矢量网络分析仪 (VNA) 测量 S 参数：

                     ┌──────────────┐
      端口 1 ──────→ │     VNA      │ ←────── 端口 2
                     └──────────────┘
                           │
                     ┌─────┴─────┐
                     │    DUT     │
                     │  (被测件)   │
                     └───────────┘

   VNA 校准步骤（以 SOLT 为例）：

   步骤 1: Short (短路)     → 测量反射
   步骤 2: Open (开路)      → 测量反射
   步骤 3: Load (50 Ω 负载) → 测量反射
   步骤 4: Through (直通)   → 测量传输

   校准后将参考面移到 DUT 端口，消除电缆和夹具的误差。

.. tip::

   **S 参数在 ADS 中的使用：**

   - S2P 文件：存储二端口 S 参数的标准格式
   - 可在 ADS 中直接导入 S2P 文件作为元件模型（如 SAW 滤波器 S 参数）
   - Touchstone 文件格式（.s2p）：业界标准
