======================================
射频设计实例
======================================

本章通过三个完整的实例串联全书知识点：从匹配网络设计、滤波器设计到 PCB 布局。

实例一：2.4 GHz L 型匹配网络
===============================

设计指标
---------

.. list-table::
   :header-rows: 1

   * - 参数
     - 值
     - 说明
   * - 频率
     - 2.45 GHz
     - WiFi / 蓝牙 / Zigbee
   * - 负载阻抗
     - 12 - j15 Ω
     - 假设芯片输出阻抗
   * - 目标阻抗
     - 50 Ω
     - 系统阻抗
   * - 匹配类型
     - L 型低通
     - 阻隔高次谐波
   * - 带宽
     - > 200 MHz (VSWR < 2:1)
     - 覆盖 ISM 频段

设计步骤
---------

.. code-block::

   步骤 1：在史密斯圆图上定位 Z_L

   z_L = (12 - j15) / 50 = 0.24 - j0.30

   步骤 2：选择拓扑
   从负载到源，先并联 C 再串联 L（低通拓扑）
   因为负载的实部 < 50 Ω，先并联提升实部到 50 Ω

   步骤 3：计算元件值

   并联电容：
   b = 1/0.24 × √(1/0.24 - 1) ≈ 1.53
   C = 1.53 / (2π × 2.45e9 × 50) ≈ 1.99 pF

   串联电感：
   x = √(1/0.24 - 1) ≈ 1.78
   L = 1.78 × 50 / (2π × 2.45e9) ≈ 5.78 nH

   步骤 4：ADS 仿真验证

   原理图：
   ┌────────────┬─────────────┬────────────┐
   │ TermG1    ┝ L=5.8 nH  ┝            ┝ TermG2
   │ Z=50 Ω   │            │ C=2.0 pF  │ Z=12-j*15
   └────────────┴────────────┴────────────┘
                              │
                             GND

   步骤 5：仿真结果
   - S₁₁ < -30 dB @ 2.45 GHz
   - VSWR < 1.2:1 在 2.3~2.6 GHz
   - 插入损耗 < 0.1 dB

   步骤 6：PCB 实现

   选择 0603 封装的 MLCC 和叠层电感：
   C ≈ 2.0 pF (村田 GRM18 系列，SRF > 6 GHz)
   L ≈ 5.6 nH (村田 LQG18 系列，SRF > 4 GHz)

   微带线宽（FR4, h=0.8mm）：≈ 1.5 mm
   焊盘寄生：约 0.3 pF → 将 C 调整为 1.8 pF

实例二：微带带通滤波器
=========================

设计指标
---------

.. list-table::
   :header-rows: 1

   * - 参数
     - 值
     - 说明
   * - 中心频率
     - 2.45 GHz
     - ISM 频段
   * - 带宽
     - 200 MHz
     - 8.2% 相对带宽
   * - 插入损耗
     - < 3 dB
     - 通带内
   * - 带外抑制
     - > 20 dB @ 2.0 GHz & 2.9 GHz
     - 邻频抑制
   * - 阶数
     - 3
     - 切比雪夫响应
   * - 纹波
     - 0.1 dB
     - 通带等波纹

设计步骤
---------

.. code-block::

   步骤 1：原型滤波器参数

   切比雪夫 0.1 dB 纹波，n=3
   g0 = 1.0, g1 = 1.0316, g2 = 1.1474, g3 = 1.0316, g4 = 1.0

   步骤 2：耦合系数和 Q 值

   外部 Q 值：Q_e1 = g0×g1 / FBW = 1.0316 / 0.082 = 12.58
              Q_e2 = g3×g4 / FBW = 1.0316 / 0.082 = 12.58

   耦合系数：
   k_{12} = FBW / √(g1×g2) = 0.082 / √(1.0316×1.1474) = 0.075
   k_{23} = FBW / √(g2×g3) = 0.082 / √(1.1474×1.0316) = 0.075

   步骤 3：微带谐振器尺寸

   选基板：Rogers 4350B (ε_r=3.5, h=0.508 mm, tanδ=0.0037)

   50 Ω 微带线宽 ≈ 1.1 mm
   谐振器长度 = λ/2 ≈ 41.6 mm @ 2.45 GHz

   步骤 4：耦合间隙提取

   使用 ADS 的耦合线模型 (MCLIN)：

   耦合器 1：W=1.1 mm, S=0.3 mm, L=λ/4 ≈ 20.8 mm
   → 仿真提取耦合系数 k_{12}

   调整间隙直到 k_{12} = 0.075

   步骤 5：ADS 仿真

   在 ADS 中构建三阶平行耦合微带滤波器：

   ┌─────────────────────────────────────────┐
   │  ────  ────  ────  ────  ────  ────  │
   │  │                          │          │
   │  ────  ────  ────  ────  ────  ────  │
   │  P1                       P2          │
   │     λ/4  λ/4  λ/4  λ/4  λ/4  λ/4     │
   └─────────────────────────────────────────┘

   步骤 6：结果

   S₂₁ 通带损耗 ≈ 2 dB
   S₁₁ < -15 dB @ 2.35~2.55 GHz
   S₂₁ < -25 dB @ 2.0 GHz

布局要点
---------

.. list-table::
   :header-rows: 1

   * - 要点
     - 实施
     - 原因
   * - 分区布局
     - RF 与数字分开
     - 避免数字噪声耦合到 RF
   * - 短走线
     - 50 Ω 走线尽量短
     - 减少损耗和辐射
   * - 地过孔
     - 每个接地焊盘 ≥ 2 个过孔
     - 降低接地电感
   * - 屏蔽罩
     - 覆盖 PA 和 LNA 区域
     - 隔离收发互相干扰
   * - 去耦电容
     - 紧靠电源引脚
     - 降低电源阻抗
   * - 地平面
     - 层 2 完整地平面
     - 保证 50 Ω 参考面

检查清单
----------

.. code-block::

   □ 所有 RF 走线阻抗是否 50 Ω？
   □ 地平面是否完整无分割？
   □ RF 走线下方是否有完整地参考？
   □ 拐角是否为 45° 或圆弧？
   □ 每个 RF 接地焊盘是否 ≥ 2 个过孔？
   □ 去耦电容是否紧靠 IC 电源引脚？
   □ PA 和 LNA 是否有屏蔽罩？
   □ 数字信号是否远离 RF 区域？
   □ 天线馈线是否最短路径？
   □ 电源线是否足够宽（承载电流）？
   □ 是否有测试点/连接器用于调试？
   □ PCB 叠层是否满足阻抗控制？
