======================================
射频无源元件
======================================

在射频频率下，理想 R/L/C 模型不再成立—— **寄生参数** 成为主导。
了解元件的高频行为是成功设计的关键。

电阻的高频模型
===============

.. code-block::

   实际电阻的等效电路模型：

          ┌─── L_lead ───┬─── C_par ───┐
          │              │            │
   ──────┤        R_{ideal}           ├──────
          │              │            │
          └──────────────┴────────────┘
                    │
                   GND

- :math:`L_{\text{lead}}` ：引线电感（贴片 0402 ≈ 0.5 nH）
- :math:`C_{\text{par}}` ：寄生并联电容 ≈ 0.05~0.3 pF
- :math:`R_{\text{ideal}}` ：标称电阻值

.. tip::

   射频中**尽量避免使用电阻**——所有电阻都伴随寄生电感和电容。
   如需衰减，使用分布参数衰减器（PI 型或 T 型电阻网络）。

电容的高频模型
================

.. code-block::

   MLCC 贴片电容的等效电路：

   ────┬─── L_ESL ───┬─── C ───┬─── R_ESR ───┬────
       │            │        │            │
       └────────────┴────────┴────────────┘

   SRF (自谐振频率):

   f_{SR} = \frac{1}{2\pi\sqrt{L_{ESL} \cdot C}}

电容值在 SRF 以下的频段呈容性，在 SRF 以上呈感性！

.. list-table::
   :header-rows: 1

   * - 标称值
     - 封装
     - SRF (典型)
     - 工作频段
   * - 100 pF
     - 0402
     - ~800 MHz
     - < 400 MHz
   * - 10 pF
     - 0402
     - ~2.5 GHz
     - < 1.2 GHz
   * - 1 pF
     - 0402
     - ~8 GHz
     - < 4 GHz
   * - 0.5 pF
     - 0402
     - ~12 GHz
     - < 6 GHz

.. note::

   射频设计中，隔直电容通常选 **100 pF ~ 1 nF** 的 MLCC。
   但需确认 SRF > 工作频率。对于宽带应用，可用**不同容值并联**
   来扩展去耦带宽。

电感的高频模型
================

.. code-block::

   绕线/叠层电感的等效电路：

   ────┬─── R_AC ───┬─── L ────┬─── C_par ───┬────
       │            │         │            │
       └────────────┴─────────┴────────────┘

- :math:`R_{\text{AC}}` ：交流电阻（趋肤效应 + 磁芯损耗）
- :math:`C_{\text{par}}` ：匝间分布电容
- 品质因数：:math:`Q = \frac{\omega L}{R_{\text{AC}}}`

.. list-table::
   :header-rows: 1

   * - 类型
     - 电感范围
     - Q 值
     - SRF
     - 适用频率
   * - 绕线
     - 1 nH ~ 1 μH
     - 30 ~ 100
     - 中
     - < 3 GHz
   * - 叠层
     - 1 nH ~ 100 nH
     - 10 ~ 50
     - 高
     - < 6 GHz
   * - 薄膜
     - 0.5 ~ 10 nH
     - 20 ~ 60
     - 很高
     - < 20 GHz
   * - 空心线圈
     - 1 ~ 100 nH
     - 50 ~ 200
     - 高
     - < 10 GHz

.. warning::

   在匹配网络中，使用**高 Q 值电感**可以减少插入损耗。
   对于 L 网络匹配，电感 Q 值直接影响匹配网络的插入损耗：

   .. math::

      \text{Loss} \approx 1 - \frac{Q_{\text{network}}}{Q_{\text{ind}}}

   其中 :math:`Q_{\text{network}}` 是匹配网络的 Q 值。

射频传输线变压器
=================

.. code-block::

   λ/4 传输线变压器（阻抗变换）：

   Z_s ──── [Z_0=√(Z_s×Z_L), λ/4] ──── Z_L

   另一种常见形式：传输线绕在磁芯上的宽带变压器：

          ┌──────┐──┬──
    Z_s ──┤ 磁芯  │  │
          │      │  ═ C
          └──────┘──┴──
   可工作于 1:1 或 1:4 阻抗变换

功分器 / 合路器
=================

威尔金森功分器
----------------

.. code-block::

   二路等分 Wilkinson 功分器：

                    ┌─── 70.7Ω, λ/4 ───┐
                    │                  │
   Port 1 (50Ω) ───┤        100Ω       ├─── Port 2 (50Ω)
                    │      隔离电阻      │
                    └─── 70.7Ω, λ/4 ───┘
                                    │
                                    └─── Port 3 (50Ω)

特性：

- 等分输出（-3.01 dB 每路）
- 端口间有隔离电阻，端口 2 和 3 间相互隔离
- 所有端口匹配（50 Ω）

定向耦合器
============

.. code-block::

   微带定向耦合器（端耦合型）：

   ┌──────────────────────────┐
   │ ──────────────────────── │  Port 1 (in) → Port 2 (out)
   │                          │
   │ ─────── 耦合间隙 ──────── │  Port 3 (耦合) → Port 4 (隔离)
   └──────────────────────────┘

   关键指标：

   耦合度：C = -20 log|S31| (dB)
   方向性：D = -20 log|S41/S31| (dB)，越高越好
   隔离度：I = -20 log|S41| (dB)

环形器 / 隔离器
=================

.. code-block::

   三端口环形器示意图：

                Port 2
                  ↑
    Port 1 → ────▓──── → Port 3

   信号流转方向：Port 1 → Port 2 → Port 3 → Port 1

   隔离器 = 其中一端接匹配负载的环形器
   特性：单向传输，反向隔离，常用于功放输出保护

.. note::

   环形器利用铁氧体的旋磁效应。
   工作频率由外加永磁体强度决定，
   是窄带器件（带宽典型 10~20%）。
